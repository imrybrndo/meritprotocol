Unlock to sign in

The password you set on this machine decrypts the key, which then signs a one-time challenge from the deployment. The signature is what authenticates you.

Forgotten your password?

It cannot be recovered. Nothing on this machine stores it — the wallet file holds only ciphertext, and there is no second copy to fall back on. Two ways back to the same address:

  1. Import its seed phrase, if you wrote one down.
  2. Import its private key, if you hold it elsewhere — MetaMask and Rabby both export one under account details.

Either restores the identical address under a new password. Without one of them, the only option left is a new wallet.
